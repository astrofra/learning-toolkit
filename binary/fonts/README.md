# Polices

Roboto (graisses 300–700) et Roboto Mono (400–700), au format WOFF2 variable, avec les jeux de caractères Latin et Latin étendu. Les quatre fichiers sont servis localement ; l’application ne contacte pas Google Fonts.

Fichiers obtenus le 7 octobre 2026 depuis [Google Fonts](https://fonts.googleapis.com/css2?family=Roboto:wght@300..700&family=Roboto+Mono:wght@400..700&display=swap). Les déclarations et plages Unicode correspondantes figurent dans `../styles/fonts.css`.

Les licences SIL Open Font License sont conservées à côté des fichiers : `roboto-OFL.txt` et `robotomono-OFL.txt`, issues des répertoires [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto) et [Roboto Mono](https://github.com/google/fonts/tree/main/ofl/robotomono) du dépôt Google Fonts.
